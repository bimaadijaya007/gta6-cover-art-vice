Vice Cover Studio: a GTA-style multi-panel cover maker. Turn your photos and a caption into poster cover art — Vice Trio, Duo or Full-bleed layouts, four sunset/neon colour grades, pan/zoom per panel, and PNG export in 1080×1080, 1080×1350 and 1920×1080. Runs fully offline in the browser; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load a photo (or use a built-in sample), pick a layout and grade, edit the caption, and export your cover.
